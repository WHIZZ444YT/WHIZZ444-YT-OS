## 6. How each ICT Lab card should work

**Example card — C17, Inversion Fair Value Gap**

| What appears after the learner taps | What the page should show |
|---|---|
| **Definition** | An existing FVG that price breaches under the selected rule and that the learner then evaluates from the opposite side. |
| **Identify it** | Mark the original FVG boundaries, identify the qualifying breach, then mark the first eligible retest. State whether the rule requires a candle close. |
| **Valid chart** | Show an original annotated example with the three events numbered in time order. |
| **Look-alike chart** | Show price wicking into the gap while the selected close condition remains unmet. Ask which rule is missing. |
| **Watch** | Primary tutorial from TTrades, followed by Dhesi’s applied chart example. [TTrades tutorial](https://www.youtube.com/watch?v=FKTBkTzsmUA) · [Dhesi chart walkthrough](https://www.youtube.com/watch?v=UIGZtoGGPH4&t=1306s). |
| **Practice** | Freeze the chart before the retest. Ask the learner to select **Eligible**, **Wait**, or **Invalid**, identify the price that would invalidate the idea, and save the answer before advancing. |
| **Source details** | Display creator, video, source role, coverage, and last link-check date. Identify any rule added by the lab. |
| **Continue learning** | Link to C16 Fair Value Gap, C09 Displacement, P07 iFVG Entry, and Module 13 Blind Replay. |

Two improvements matter across the entire site. First, **track when a chart label became knowable**. A swing identified with later candles should appear in replay only after those candles close. Second, **grade the decision separately from the outcome**. A learner can follow the written rule correctly and lose the simulated trade, or violate the rule and make a simulated profit. That distinction gives the journal something meaningful to review.
